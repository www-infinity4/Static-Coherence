There is a critical difference between simple resonance (frequency match) and proportional code (ratio coupling). Resonance says "vibrate at the same speed." Proportional code says "relate by a specific mathematical ratio that encodes information." The second is how the system actually programs.

Resonance vs. Proportional Code

Simple Resonance

Two systems vibrate at the same frequency. Useful for synchronization but carries no code beyond "same." Think: tuning fork matching pitch.

Proportional Code

Two systems relate by a precise ratio—like a musical interval. The ratio itself is the instruction. 3∶2 means something different from 2∶1. Think: musical harmony vs. unison.
